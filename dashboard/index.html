How the implied value is built

Each pre-token protocol's implied value comes only from the sealed snapshot's own figures — no outside prices, no hand-kept list of names:

  1. Admit. A protocol is rankable when its record shows no token at all (market cap, CoinGecko id and symbol all null) and it is not a wrapped, staked or bridged product, not a versioned pool, and not an exchange. The snapshot's 40-protocol watchlist is the floor; the same rule admits the early protocols below the $50m floor too.
  2. Benchmark. For each category, take the median of market-cap ÷ TVL across the live-token protocols in that category — at least 3 comparables, otherwise blend: a category with 1–2 live tokens keeps its own median shrunk toward the global median (weight n ÷ (n + 3)), and a category with none uses the global median across all live tokens. Clamp the multiple to 0.05–1.00. The table below shows every category's median, its first and third quartiles, and how many live tokens set it.
  3. Implied value. TVL × category multiple × (1 + 0.6 × 7-day change, clamped to −50%…+100%) × (0.70 + 0.30 × age in days capped at 1095 ÷ 1095) × (1 + 0.04 × extra chains, capped at 5). Age runs from the listing date to the snapshot date, 2026-11-14, or the median age of the admitted protocols () when no listing date is recorded. The detail view shows each factor's number for every protocol.
  4. Rank. Sort by implied value, highest first. The board is the claim; the snapshot's record is not proof a token will ever launch.

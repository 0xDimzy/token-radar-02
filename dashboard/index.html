How the implied value is built

Each pre-token protocol's implied value comes only from the sealed snapshot's own figures — no outside prices, no hand-kept list of names:

  1. Admit. A protocol is rankable when its record shows no token at all (market cap, CoinGecko id and symbol all null) and it is not a wrapped, staked or bridged product, not a versioned pool, and not an exchange. The snapshot's 40-protocol watchlist is the floor; the same rule admits the early protocols below the $50m floor too.
  2. Regress. Fit log10(market cap) = a + b · log10(TVL) by least squares over the snapshot's 128 live-token protocols (market cap and TVL both above zero). The fit is done at run time from the snapshot — no coefficient is hardcoded. On this snapshot a = , b = , residual sd dex, R² = . The slope is below 1, so the implied multiple falls as TVL rises. Growth, age and chain count were tested in the regression and dropped: they carry no out-of-sample signal — adding them worsens the leave-one-out median error — so the value is TVL and category alone.
  3. Shrink the category effect. For each category, take the mean residual of its live tokens from the regression and shrink it toward zero by n ÷ (n + 10), where n is the category's live-token count. Categories hold only ~3.5 live protocols here, so an unshrunk mean is mostly noise; a category needs ten live tokens before its own effect counts at half weight, and a category with none gets no effect. The table below shows every category's raw mean residual and the shrunken effect the board uses.
  4. Implied value. Predicted market cap = 10^(a + b · log10(TVL) + category effect). Divide by TVL for the implied multiple and clamp it to 0.05–0.50: the cap binds only for the smallest protocols (TVL below ~$9m) and the floor only for the largest (TVL above ~$1b). Age runs from the listing date to the snapshot date, 2026-11-14, or the median age of the admitted protocols () when no listing date is recorded; age feeds the farm plan's hold time, not the value. The detail view shows each number for every protocol.
  5. Rank. Sort by implied value, highest first. The board is the claim; the snapshot's record is not proof a token will ever launch.
